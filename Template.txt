ADMIN- SIDE
1) Signup and Sign. After this it routes to the home page.
2) Home Page will be the dashboard. It will have a Nav Bar with following pages (exclude dashboard from the nav bar)-
	i) Dashboard (Data visualization of all the calamities)- number of requests to the server from particular city,state, resources required for each state, incident severity level, type of disaster and in which state.

	ii) Incidents (Incident Description)- This will contain a list of all the ongoing incidents. It will contain the incident description, the severity tag(which admin can decide), the location of the incident, photos from the user. Each incident will be a unique set of- City + Disaster_Type. 

	iii) Resources Deployement- Each incident document will have a send resources button, which will route to this page. Here, we can see the resources to be sent. We can add the resources and then send it. It'll be list of items. We can add each item. The description of the resources will also be available. The status of the deployment will be next to add to cart,
and description will be below it. Each incident will be a unique set of- City + Disaster_Type.

	iv) Communication (Chat Application)- we will have a chatbox, where we can have a realtime communication between the user and the admin

	
	vi) Logout
